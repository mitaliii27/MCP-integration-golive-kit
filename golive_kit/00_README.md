# Go-live kit: from customer workshop to hypercare (AI agent engagements)

Reusable templates for taking an AI-agent use case from first workshop to production support. They are generic starting points - adapt wording, thresholds and roles to the customer. Worked examples of the same artefacts live in `01-s4-procurement-agent/docs/` (functional spec) and this repo's `results/` (measured integration behaviour).

| # | Document | Used when |
|---|---|---|
| 01 | Discovery workshop agenda | Week 0-1 |
| 02 | Discovery questionnaire | Before/after the workshop |
| 03 | Functional specification template | Weeks 1-3 |
| 04 | Test plan & UAT checklist | Before go-live |
| 05 | Cutover runbook | Go-live week |
| 06 | Hypercare plan | First 2-4 weeks live |
| 07 | Security & responsible-AI checklist | Design review + before go-live |
| 08 | Demo script | Stakeholder demos |
