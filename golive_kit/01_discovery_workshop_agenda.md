# Discovery workshop - 2 hours

**Goal:** leave with one prioritised use case, named owners, data/system access paths and measurable success criteria.
**Attendees:** business process owner, 1-2 end users, IT/integration lead, security/data-protection representative, delivery lead, developer.

| Time | Topic | Output |
|---|---|---|
| 0:00-0:10 | Objectives, ground rules, what an agent can and cannot do | Shared expectations |
| 0:10-0:35 | Walk the current process end to end (screen-share a real example) | As-is flow, pain points, volumes |
| 0:35-1:00 | Use-case shortlist and scoring (value x feasibility x risk) | Ranked list; one chosen |
| 1:00-1:20 | Systems & data: which APIs, which fields, auth, environments | Integration inventory |
| 1:20-1:40 | Guardrails: what must never happen? what needs human approval? | Draft policy table |
| 1:40-1:55 | Success metrics and acceptance thresholds | Metrics with owners |
| 1:55-2:00 | Next steps, dates, open questions | Action list |

## Facilitation notes
- Insist on a *real* recent example before discussing the ideal flow.
- Write down "must never" statements verbatim - they become guardrail tests.
- If the customer cannot name an owner for a success metric, it is not yet a metric.
